# what2eat · 今天吃什么

一个"帮你做决定"而不是"让你做选择题"的吃饭决策小程序。

录入身体数据后，它直接告诉你：今天能吃多少、这一顿具体吃什么（主餐+饮品的完整搭配，含热量与营养素）、下一顿该怎么收着吃。今天想放纵，开关一拧，当日预算上浮 30%，超的部分后面几天自动匀回来。

**纯前端、无后端、零上传**：所有数据只存在你手机本地（微信 storage），不请求任何业务服务器。

## 功能

- **每日预算**：Mifflin-St Jeor 基础代谢 × 活动系数，按目标（减脂/维持/增肌）调整，三餐 3:4:3 配额
- **搭配推荐**：主餐 + 饮品的组合，显示总热量、蛋白/碳水/脂肪、占本餐预算比例；口味/品类/价格带加权随机，忌口硬排除，"换一个"不重复
- **放纵模式**：当日预算 ×1.3，推荐池放开高糖高油并必配饮品；超支部分未来 3 天每天扣回 1/3（可切换成"只记账不惩罚"）
- **步数额度**：输入今日步数，按体重换算额外消耗自动加到当日预算（70kg · 10000 步 ≈ +315 kcal）
- **附近搜店**：接入高德周边搜索，按品类搜 1.5km 内的店，点一下唤起微信内置地图导航
- **自定义食物**：食堂窗口、家门口那家店，都能加进推荐池
- **账本**：近 7 天摄入 vs 预算，超支红字、放纵日打标、步数留痕

## 快速开始

1. 注册微信小程序（个人主体，免费）：mp.weixin.qq.com
2. 下载微信开发者工具，导入本项目目录，AppID 填你自己的（或先用"测试号"）
3. 工具里即可预览；点"预览"扫码，手机上以开发版运行，**无需发布审核**

算法层自带离线单测（无任何依赖，改了公式/引擎可以自验）：

```bash
node tests/test-algo.js    # 预算/推荐引擎 28 项断言
node tests/test-batch2.js   # 步数/自定义食物/复合场景 23 项断言
```

## 附近搜店（可选，需要自己的高德 Key）

1. 到 lbs.amap.com 注册高德开放平台个人开发者（免费）
2. 创建 Key，**服务平台选「Web服务」**（选错类型会返回异常）
3. 小程序「我的 → 高德Key」里填入即可。Key 只存在手机本地，不进代码、不上传

> 开发/体验版已在 project.config.json 关闭域名校验；正式发布需在小程序后台把 `restapi.amap.com` 加入 request 合法域名，并按平台要求完成用户隐私保护指引声明。

## 营养口径（先读这个）

- 食物热量为**品类级估算，误差 ±20%**：本工具做的是预算管理，不是精确计量；页面底部有同款声明
- BMR：Mifflin MD, St Jeor ST, et al. Am J Clin Nutr. 1990;51(2):241-247
- 活动系数：FAO/WHO/UNU Human Energy Requirements (2004)，1.2–1.9 分段
- 步耗：每步 ≈ 体重(kg) × 0.00045 kcal，参照公开步耗估计（10000 步 ≈ 300–400 kcal @70kg）
- 本工具不构成医疗建议；有疾病或特殊营养需求请遵医嘱

## 目录结构

```
what2eat/
├── app.js / app.json / app.wxss      # 全局入口、Tab 与定位权限、全局样式
├── project.config.json               # 开发者工具项目配置
├── data/foods.js                     # 内置食物库（146 条，品类级营养估算）
├── tests/                            # 算法层离线单测（node tests/ 直接跑）
├── utils/
│   ├── nutrition.js                  # BMR/TDEE/预算/超支分摊/步数换算（纯函数，可单测）
│   ├── recommender.js                # 搭配推荐引擎（偏好加权随机）
│   └── store.js                      # 本地存储层（profile / log / 自定义食物 / 高德Key）
└── pages/
    ├── today/                        # 今日：预算、推荐、步数、附近搜店
    ├── record/                       # 记录：今日明细 + 近 7 天账本
    ├── me/                           # 我的：资料、偏好、Key 配置、数据清空
    └── food/                         # 自定义食物管理
```

## 已知限制与路线图

- **自动步数**：`wx.getWeRunData` 返回加密数据，解密需要 session_key（AppSecret 不能放进前端代码），纯前端拿不到明文。当前为手动输入步数 + 自动换算；后续计划提供可选云函数实现自动拉取
- **支付账单导入**：支付宝/微信支付账单 CSV 导入，自动生成偏好画像（计划中）
- **数据导出/备份**：计划中
- 食物库为品类级：没有具体品牌/门店的精确热量
